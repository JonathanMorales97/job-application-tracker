- **Qué hice:**

- **Qué aprendí:**
    clave : valor -> Se usa para un objeto dentro de un array
    () => se aplica para una funcion lambda, funcion corta sin nombre que se pasa como argumento
    Filter -> devuelve un array nuevo solo con los elementos que cumplan la condición
    Map -> devuelve un array nuevo con cada elemento transformado
    find -> devuelve el primer elemento que cumple la condición o undefined si no hay ninguno
    Un const sobre un array permite hacerle push
